# Hi, I'm Joe 👋

Data scientist who ships. I work at the intersection of graph analytics, machine learning, and the infrastructure needed to put a model in production.

My public work is small and deliberate — a handful of repos I actually finished rather than a pile of half-starts.

## What I'm into

- **Graph data science** — Neo4j, NetworkX, node embeddings, and centrality algorithms that run against a live database instead of an in-memory copy
- **ML in production** — training a model, wrapping it in an API, containerizing it, and load-testing the result
- **Interview prep** — working through algorithm problems for muscle memory, not for show
